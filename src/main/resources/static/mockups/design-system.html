CycleTime Design System

Foundation Components & Design Tokens

Introduction

This design system establishes the visual language and component library for the CycleTime dashboard. It prioritizes developer experience, information density, accessibility, and professional credibility.

Design Principles

  • Function Over Form - Every design choice serves a user need
  • Information Density - Maximum relevant information without overwhelming
  • Predictable Patterns - Consistent components reduce cognitive load
  • Accessible by Default - WCAG 2.1 AA minimum compliance
  • Performance Conscious - Fast loading matters more than visual complexity

Badge padding, compact spacing

Default spacing, card padding start

space-5 / 20px

Section spacing

space-6 / 24px

Card padding, component separation

space-8 / 32px

Major section separation

space-12 / 48px

Page margins, hero spacing

space-16 / 64px

Maximum separation

Common Spacing Patterns

Card Padding

p-6 (24px) - Desktop cards

p-4 (16px) - Mobile cards

Button Padding

px-3 py-1.5 - Small (12px / 6px)

px-4 py-2 - Medium (16px / 8px)

px-6 py-3 - Large (24px / 12px)

Section Spacing

mb-8 (32px) - Between sections

gap-4 (16px) - Between cards (tight)

gap-6 (24px) - Between cards (comfortable)

Page Margins

px-8 py-6 - Desktop (32px / 24px)

px-6 py-4 - Tablet (24px / 16px)

px-4 py-3 - Mobile (16px / 12px)
